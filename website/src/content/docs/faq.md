## 触摸芯片到底是什么？

GT911。结构图明确标注 GT911，仓库不会使用 FT5446U 驱动。

## 现在已经有可用的正式驱动吗？

还没有。仓库已经公开资料和清理后的参考工程，正式 `openepd47` 组件仍按驱动计划开发。

## 为什么 GT911 数据手册没有放进仓库？

找到了公开来源，但没有确认该第三方 PDF 的再分发许可。因此网站只保存来源链接，驱动代码使用乐鑫官方 Apache-2.0 组件。

## 资料可以用于开源项目吗？

资料提供方已向项目发起人确认所获厂商资料可以公开。仓库仍分别标注第三方许可证和授权边界。

## 如何提交自己的项目？

项目展示区使用 GitHub Issue Form 和 PR，不需要网站账号。提交时需要说明仓库链接、硬件、框架、许可证和图片使用权。

## 网站为什么使用 GitHub Pages？

它与开源仓库、PR 审核和版本历史天然衔接，不需要额外后端，适合当前规模。
