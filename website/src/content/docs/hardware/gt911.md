本模组的触摸控制器是 **GT911**，不是 FT5446U。

## 官方驱动

正式实现优先使用乐鑫维护的组件：

- [乐鑫组件仓库：`espressif/esp_lcd_touch_gt911`](https://components.espressif.com/components/espressif/esp_lcd_touch_gt911)
- [乐鑫 ESP-BSP 源码](https://github.com/espressif/esp-bsp/tree/master/components/lcd_touch/esp_lcd_touch_gt911)

计划锁定的依赖：

```yaml
dependencies:
  espressif/esp_lcd_touch_gt911: "1.2.0~3"
```

执行驱动计划时应重新确认组件最新兼容版本，再由 CI 锁定。

## 板级适配负责什么

官方组件处理 GT911 通用协议；OpenEPD 4.7 板级层负责：

- I²C 总线与地址选择。
- RST/INT 上电时序。
- 0–5 点触摸数据读取。
- 684×1216 坐标边界。
- 0°、90°、180°、270° 方向转换。
