## GT911 触摸 FPC

结构图标注的 6 针触摸接口如下：

| 信号 | 作用 |
|---|---|
| VDD | 触摸控制器供电 |
| GND | 地 |
| SDA | I²C 数据 |
| SCL | I²C 时钟 |
| RST | 硬件复位 |
| INT | 中断与地址选择配合 |

## 参考工程 I²C

厂商参考固件中使用：

| 信号 | ESP32-S3 GPIO |
|---|---|
| SDA | GPIO39 |
| SCL | GPIO40 |

这些是**当前参考板级配置**，不是所有兼容控制板的通用引脚。正式驱动会将它们集中到 `openepd47_board.h`，避免示例散落魔法数字。

## 接线原则

- 断电后再插拔显示和触摸 FPC。
- 核对 FPC 金手指方向。
- 不要用 FT5446U 的引脚或初始化流程替代 GT911。
- 供电前先阅读 [TPS65185 电源](/openepd-47/hardware/power/)。
