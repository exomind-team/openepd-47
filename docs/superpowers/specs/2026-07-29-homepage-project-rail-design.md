# 首页首屏项目轨道设计

**日期：** 2026-07-29  
**状态：** 已确认  
**选择方案：** B「轨道切入」

## 目标

用户打开首页时，无需纵向滚动就能看到项目列表。项目以横向轨道压在主视觉底部，
支持左右浏览；完整项目库和投稿入口继续保留在 `/projects/`。

资料展示区改用直接陈述，不再使用“不是……而是……”句式。

## 首屏结构

首页首屏由三层组成：

1. 顶部导航：保持现有品牌、文档、资料、项目和 GitHub 入口。
2. 主视觉：保留 OpenEPD 标题、核心说明、开发/资料按钮和电子纸示意图。
3. 项目轨道：作为浮动档案层压在主视觉下缘，首屏内始终可见。

桌面端首屏高度以 `100svh` 为基准。项目轨道位于首屏底部并覆盖主视觉下缘，
卡片高度约 150–180 px；首张和第二张卡片完整可见，第三张至少部分可见。

移动端缩短主视觉、隐藏非必要的大尺寸示意细节。项目轨道固定在首屏底部，
单张卡片宽度约为视口的 80–86%，确保第一张完整可见且下一张露出边缘。

## 项目轨道

新增独立的 `HomeProjectRail.astro`，直接读取 `src/data/projects.ts`，避免首页和
项目库维护两份数据。

轨道包含：

- “项目展示 / Projects”标题和“查看全部”链接。
- 项目状态、分类、名称、硬件和框架。
- 原生 `overflow-x: auto` 与 `scroll-snap`，支持触摸、触控板和键盘。
- 左右控制按钮，作为桌面端补充操作；无 JavaScript 时仍可原生滚动。
- 可见的下一张卡片边缘，作为横向滚动提示。

项目卡点击后进入对应仓库或投稿 Issue；不在首页复制长摘要和完整许可证信息。

## 页面内容调整

- 删除首页主视觉中的独立“项目展示”文字按钮，以项目轨道标题和卡片替代。
- 删除原有“三个入口”区和页面末尾的项目占位大面板，避免重复展示。
- 开发和资料入口继续保留在主视觉按钮中。
- `/projects/` 页面保持完整筛选、项目详情信息和投稿入口。
- 资料区标题改为“已整理的硬件资料”，正文直接说明规格书、结构图、GT911
  触摸资料、TPS65185 电源资料、来源、授权状态和 SHA-256。

## 响应式与无障碍

- 1366×768、1440×900 和 390×844 视口初始画面都必须出现项目轨道。
- 页面本身不得产生横向溢出；只有项目轨道内部允许横向滚动。
- 轨道使用具名区域，控制按钮具有中文 `aria-label`。
- 项目卡保持可聚焦；减少动态效果偏好下关闭非必要动画。
- 控制按钮滚动一个卡片宽度，并在轨道到达两端时更新禁用状态。

## 验证

Playwright 测试覆盖：

1. 首页首屏存在三个项目卡，项目轨道底部坐标不超过视口高度。
2. 轨道 `scrollWidth` 大于 `clientWidth`，执行向右操作后 `scrollLeft` 增加。
3. 390×844 下项目轨道首屏可见，且页面根元素无横向溢出。
4. 资料标题为“已整理的硬件资料”，页面不出现“不是‘文件堆’”文案。
5. 既有资料、文档和项目页测试继续通过。

## 非目标

- 不删除 `/projects/` 完整项目页。
- 不新增后端、轮播库或自动播放。
- 不在本次调整中修改项目数据 Schema 或投稿流程。
